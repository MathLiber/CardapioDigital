# CardapioDigital
Cardápio digital do Instituto Federal Campus São João da Boa Vista do refeitório.

**Problema:**
- Falta de conhecimento prévio a respeito do cardápio do dia.

**Público Alvo:**
- Estudantes

**Solução:**
- A criação de um cardápio digital que é atualizado diariamente mostrando o que será servido.
